# Language Bindings[](#language-bindings "Permalink to this heading")

API specifications for official NCCL language bindings.

The core NCCL API is implemented in C/C++ (see [NCCL API](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/api.html#api-label)). Language bindings provide wrappers around that implementation to enable NCCL functionality in other programming languages.

  * [Python Bindings (NCCL4Py)](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/nccl4py.html)
