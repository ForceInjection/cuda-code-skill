# Troubleshooting[](#troubleshooting "Permalink to this heading")

Use the pages below to narrow the problem down before changing NCCL settings.

  * [GPU troubleshooting](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/gpu_troubleshooting.html) covers GPU-to-GPU, GPU-to-NIC, ACS, topology, and multi-node NVLink issues.

  * [Networking Troubleshooting](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/networking_troubleshooting.html) covers interface selection, low-level fabric checks, latency and bandwidth tests, and InfiniBand or RoCE diagnostics.

  * [Runtime and MPI issues](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/runtime_and_mpi_issues.html) covers basic error handling, shared-memory and runtime problems, and MPI startup validation.

  * [Performance and tuning](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/performance_and_tuning.html) covers baseline performance triage and NCCL tuning knobs to try after system checks look healthy.

  * [Logging](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/logging.html) covers NCCL logging levels, subsystem filters, output files, and timestamps.

  * [RAS](https://docs.nvidia.com/deeplearning/nccl/user-guide/docs/troubleshooting/ras.html) covers NCCL’s built-in RAS subsystem for diagnosing hangs and crashes.
